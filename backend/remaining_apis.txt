1. Endpoint: GET /courses/search

Purpose:
Searches and filters courses by keyword or category so a visitor can find the
right course. The database already stores a semantic embedding for every course
and has an HNSW index on it, so this can return the most relevant courses for a
search term instead of only exact name matches.

Used By:
Next.js frontend course listing page (search box and category filter).

Why We Need It Now:
The current website is a course catalog of 24 courses across 7 categories
(Children, Adults, Females, Language, Short Courses, etc.), but a visitor can
only browse the full unsorted list. There is no way to search or filter, so a
user looking for a specific course (e.g. an adult tajweed course) has to scroll
through everything. Course search is core to the current course-browsing
functionality, and the embedding + HNSW infrastructure for it already exists in
the database and seed scripts but is not yet exposed by any endpoint.
